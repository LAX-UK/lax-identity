# Security policy

Report suspected vulnerabilities privately through the GitHub Security Advisory
for `LAX-UK/lax-identity`. Do not open a public issue or include credentials,
tokens, private keys, production data, or exploit details in logs.

Include the affected commit, impact, reproduction steps using synthetic data,
and any proposed mitigation. Maintainers will acknowledge the report, assess
severity, coordinate remediation, and disclose only after affected systems are
safe.

Only the current `main` branch is supported. A green CI run proves source and
image gates; it is not production promotion evidence.
